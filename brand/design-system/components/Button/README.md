# Button

Rounded 14px, padding 14px top and bottom, 24px sides. Label in Poppins bold 18px.

- **Primary** (`pb-btn`): orange fill, white label. Pressed: darker orange.
- **Secondary** (`pb-btn pb-btn--secondary`): soft gray fill (`surface`: #E5E5E5 in light, #2C2C2C in dark), label in the text color (gray-dark in light, white in dark). Pressed: slightly darker fill. Same shape in both themes.

One primary button per screen; orange stays the only strong color. Labels are verbs: "Book now", "Message sitter".
